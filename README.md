# 🚀 Subscription Tracker (ระบบติดตามการจ่ายค่า Subscription)

เว็บแอปพลิเคชันสไตล์ Minimal สำหรับใช้ส่วนตัวกับกลุ่มเพื่อน 3 คน (ปุน, ธี, พีท) เพื่อติดตามการจ่ายเงินค่า Subscription รายเดือน (คนละ 63 บาท โอนก่อนวันที่ 13) โฮสต์บน **GitHub Pages ฟรี 100%** บันทึกข้อมูลลง **Google Sheets** และสแกน QR Code ตรวจสอบสลิปซ้ำอัตโนมัติ

---

## ✨ ความสามารถหลัก

1. **แสดงสถานะชัดเจนในหน้าเดียว:**
   - แสดงกล่องสถานะ ปุน, ธี, พีท (🟢 จ่ายแล้ว / ยังไม่จ่าย)
   - มีปุ่ม "ดูสลิป" เพื่อตรวจสอบรูปสลิปย้อนหลังได้ตลอดเวลา
2. **PromptPay / SCB My QR:**
   - เลือกว่าจะให้ระบบสร้าง QR Code พร้อมเพย์ยอด 63 บาทอัตโนมัติ หรือจะใช้รูปมายคิวอาร์ (SCB My QR) จากแอป SCB EASY ก็ได้
3. **สแกนสลิป & ป้องกันสลิปซ้ำในตัว (ไม่ต้องใช้ SlipOK):**
   - เมื่อเพื่อนแนบรูปสลิป (ลากวาง / อัปโหลด / กด `Ctrl + V` วางรูป) ระบบจะสแกน Mini-QR บนสลิปทันที
   - ตรวจจับรหัสธุรกรรม (Transaction Ref) หากส่งสลิปเดิมซ้ำ ระบบจะปฏิเสธทันที
4. **Google Sheets Database (ฟรี 100%):**
   - บันทึกประวัติการจ่ายเงินลง Google Sheet อัตโนมัติ ปลอดภัย และเปิดดูย้อนหลังได้ตลอด

---

## 📁 โครงสร้างโปรเจกต์

```text
├── index.html              # หน้าเว็บหลัก (Minimal UI + jsQR)
├── config.js               # ตั้งค่า (ยอดเงิน 63 บ., รายชื่อเพื่อน, เบอร์พร้อมเพย์/รูป SCB My QR)
├── app.js                  # ระบบหน้าเว็บ (สแกนสลิป, ตรวจสอบ, แสดงผล)
├── google-apps-script.js   # โค้ดหลังบ้าน (ก๊อปไปวางใน Google Apps Script)
└── README.md               # คู่มือการใช้งาน
```

---

## 🛠️ ขั้นตอนที่ 1: ตั้งค่า Google Sheet หลังบ้าน (ทำครั้งเดียว ~2 นาที)

1. เข้าไปที่ [Google Sheets](https://sheets.google.com) แล้วสร้าง **สเปรดชีตใหม่** 1 ไฟล์ (ตั้งชื่อว่า `Gemini Subscription`)
2. เมนูด้านบน กด **ส่วนขยาย (Extensions)** > **Apps Script**
3. ลบโค้ดเดิมออกทั้งหมด แล้วนำโค้ดในไฟล์ [`google-apps-script.js`](./google-apps-script.js) ไปวาง
4. กดปุ่มสีน้ำเงิน **ทำให้ใช้งานได้ (Deploy)** > **การทำให้ใช้งานได้รายการใหม่ (New deployment)**
   - เลือกประเภท (รูปฟันเฟือง): **เว็บแอป (Web app)**
   - คำอธิบาย: `v1`
   - ดำเนินการในฐานะ: **ฉัน (Me)**
   - ผู้มีสิทธิ์เข้าถึง: **ทุกคน (Anyone)** *(สำคัญมาก ต้องเลือกทุกคน)*
5. กด **ทำให้ใช้งานได้ (Deploy)** และอนุมัติสิทธิ์ (Authorize access)
6. ก๊อปปี้ **URL เว็บแอป (Web app URL)** (ขึ้นต้นด้วย `https://script.google.com/macros/s/.../exec`)

---

## ⚙️ ขั้นตอนที่ 2: ตั้งค่าใน `config.js`

เปิดไฟล์ `config.js` แล้วตั้งค่า:

```javascript
    receiver: {
        name: "ชื่อบัญชี SCB ของคุณ",
        promptpayType: "phone",
        promptpayNumber: "08XXXXXXXX", // เบอร์โทร หรือเลขบัญชี SCB
        customQrImage: "scb-qr.png"     // หากมีรูปมายคิวอาร์ SCB ให้นำมาวางในโฟลเดอร์นี้
    },

    backendApiUrl: "URL_เว็บแอป_ที่ได้จากขั้นตอนที่_1",
    demoMode: false // ปิดโหมด Demo เพื่อใช้งานจริง
```

---

## 🌐 ขั้นตอนที่ 3: อัปขึ้น GitHub Pages

1. สร้าง Repository ใหม่บน GitHub (เช่น `gemini-sub`)
2. อัปโหลดไฟล์ทั้งหมดขึ้น GitHub
3. ไปที่แท็บ **Settings** ของ Repository > เมนูด้านซ้ายเลือก **Pages**
4. ในส่วน **Build and deployment**:
   - Source: เลือก **Deploy from a branch**
   - Branch: เลือก **main** และโฟลเดอร์ **/ (root)** > กด **Save**
5. รอ 1-2 นาที คุณจะได้ลิงก์หน้าเว็บ เช่น: `https://YOUR_USERNAME.github.io/gemini-sub/` ส่งให้ ปุน, ธี, พีท ใช้งานได้ทันที!
